# ⌨️ Тренажёр слепой печати (TypingTrainer)

Десктопное приложение для Windows, созданное для развития навыков скоростной и слепой печати. Проект написан на C# с использованием WPF и паттерна MVVM. 

## ✨ Основные возможности

*   **Три режима печати:**
    *   ⌨ **Свободная тренировка** — печать случайных текстов из базы данных.
    *   ⏱ **Тестирование на время** — режим на 60 секунд, где нужно успеть напечатать как можно больше символов.
    *   🎯 **Уровни (1–90)** — поэтапное обучение: от простых парных сочетаний клавиш до длинных слов и словосочетаний.
*   **Динамичная визуализация (в стиле osu!):**
    *   Посимвольная подсветка текста (зеленый — верно, красный — ошибка, серый — ожидание).
    *   **Система Combo:** счетчик правильных нажатий с пружинистой анимацией, которая меняет цвет (от белого до ярко-красного) и свечение в зависимости от серии.
    *   Тряска экрана при совершении ошибки.
    *   Параллакс-эффект: анимированный фон, реагирующий на движение курсора мыши.
*   **Аутентификация и роли:**
    *   Регистрация и вход с валидацией данных.
    *   Безопасное хранение паролей (хеширование BCrypt).
    *   Две роли: Пользователь (User) и Администратор (Admin).
*   **Статистика и рейтинги:**
    *   Подсчет скорости (WPM), точности (%), количества ошибок и времени.
    *   Личный профиль с возможностью смены пароля и редактирования ФИО.
    *   Общий рейтинг (Топ-50) среди всех пользователей.
*   **Панель Администратора:**
    *   Управление пользователями (просмотр, удаление с защитой от удаления администраторов).
    *   Управление текстами (добавление новых текстов с выбором сложности, удаление).

## 🛠 Используемые технологии

*   **Язык и платформа:** C# / .NET 8.0 / WPF (Windows Presentation Foundation)
*   **Архитектурный паттерн:** MVVM (Model-View-ViewModel)
*   **База данных:** SQLite (System.Data.SQLite)
*   **Безопасность:** BCrypt.Net-Next (для хеширования паролей)
*   **Анимации и UI:** WpfAnimatedGif (для гифок), встроенные Storyboard и DoubleAnimation, кастомная цветовая палитра.
